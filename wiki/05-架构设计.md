# 05 - 架构设计：直连优先 + Mac 中转兜底

## 需求背景

- 用户明确要求：**电视直接拉流优先**，笔记本做服务端中转只做兜底
- 不做系统服务（launchd），用户偶尔看电视，手动 `python3 tv.py` 启停

## 模式一：直连（首选）

```
遥控器点击 → tv.py → SOAP SetAVTransportURI(公网m3u8) → 电视自己拉流播放
```
- 零转码、零中转、延迟最低（3-8 秒出画面）
- Mac 只发两条 SOAP 指令，不参与数据面
- 风险：公网源卡顿/失效时电视端体验差 → 需要兜底

## 模式二：Mac 中转（兜底）

```
tv.py → ffmpeg 拉公网源 → 转码 1080p/3.5Mbps HLS 切片(2s/片, 列表保6片)
      → 电视拉 http://192.168.1.9:8899/hls/chN/live.m3u8
```
ffmpeg 参数（逐项理由）：
```
-y                      # 覆盖输出文件（否则交互式挂死）
-vf scale=-2:1080       # 4K 源降到 1080p（电视直拉 4K 会卡）
-c:v libx264 -preset veryfast
-b:v 3500k -maxrate 4500k -bufsize 9000k   # 稳定码率，局域网千兆随便跑
-c:a aac -b:a 128k -ac 2
-f hls -hls_time 2      # 2 秒切片，起播快
-hls_list_size 6        # 滚动窗口，磁盘不涨
-hls_flags delete_segments+append_list+omit_endlist+independent_segments
                        # 关键: omit_endlist —— 无 ENDLIST 电视才知道是直播不会"播完即停"
```

**中转的适用场景**：
1. 直连 12 秒未确认 PLAYING（源慢/挂）
2. 4K 源电视直拉卡（转码降码率）
3. 海外源需走 7890 代理（电视不会用代理，Mac 会）

## 自动降级逻辑

```
play(idx, src_idx) 异步线程:
    SOAP Set+Play(直连URL)
    循环 6 次 × 2 秒查 GetTransportInfo
        PLAYING → 定格直连模式, 结束
        NO_MEDIA_PRESENT → 立即跳出
    (超时/失败) → 起 ffmpeg 中转, Set+Play(本机HLS地址)
```

接口设计为**立即返回**（`{"ok":true,"mode":"starting"}`），后台线程做确认与降级——
否则遥控器点击要卡 30 秒（本案实际踩过：同步等状态时 curl 超时）。

## 多源切换（用户需求）

数据结构：
```python
CHANNELS = [
    {"name": "CCTV-13 新闻",
     "sources": [
         {"url": "http://112.123.243.37:50085/tsfile/live/0014_1.m3u8?...", "proxy": False},
         {"url": "http://125.125.236.31:9901/tsfile/live/0013_1.m3u8?...", "proxy": False},
         # ... 5 条线路
     ]},
]
```
- sources 顺序即优先级，验证过的真源排前
- API：`GET /api/play/{ch}?src={k}`
- 页面：当前频道下方渲染「线路 1 2 3…」按钮，当前线路高亮

## API 一览

| 接口 | 作用 |
|------|------|
| `GET /` | 网页遥控器 |
| `GET /api/channels` | `[{name, nsrc}]` |
| `GET /api/play/N?src=K` | 播放（异步，立即返回） |
| `GET /api/stop` | 停止 |
| `GET /api/status` | `{ch, src, mode, state, name, nsrc}` |
| `GET /hls/chN/live.m3u8` | 中转切片（仅兜底模式） |

## 遥控器页面要点

- 单 HTML 内嵌（无外部依赖），手机浏览器直接开
- 4 秒轮询 /api/status 刷新状态（直连/中转 + 播放状态 + 当前线路）
- 多源频道才显示线路条（`nsrc>1`）
