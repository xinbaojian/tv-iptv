# 02 - ADB 之死：为什么这台电视装不了 APK

## 结论先行

**这台海信 VIDAA 国行系统无法远程安装 APK**：
- 工厂菜单里没有「ADB 调试」选项（有：To Fac、母板清空、USB升级、串口调试、设置MAC、屏检、内置图卡）
- 全端口（1-65535）无任何 adb 监听（5555/5037/5554/7555 全部 ConnectionRefused）
- 网传教程（声音平衡按 1969 → 工厂菜单 → 开 ADB）对 2019 后的国行 VIDAA 无效

**装 APK 的唯一路径 = U 盘**：APK 拷 U 盘根目录 → 插电视 USB → 弹窗安装。

## 工厂菜单进出

### 进（两种）
- 老系统：设置 → 声音 → 高级设置 → 声音平衡 → 数字键 `1969`
- VIDAA 新系统：设置 → 声音 → 声音平衡 → 遥控器色键 红绿蓝黄红 → 工厂菜单 → 「To Fac」改值

### 退（按序尝试）
1. 菜单内找「退出工厂模式」选项
2. 长按遥控器电源键重启
3. 拔电源线 10 秒（最可靠，工厂菜单是临时界面）

### ⚠️ 红线
工厂菜单里**绝对不动**：屏参/Panel、白平衡、母板清空、初始化——改错屏参会黑屏点不亮，只能售后。方向键浏览无害，别按 OK。

## 本案放弃 ADB 后的替代路线评估

| 路线 | 结论 |
|------|------|
| ADB 远程装 APK | ❌ 不存在此通道 |
| U 盘装 APK（DIYP/百川/TVBox） | ⭕ 可行但需人工；聚好看白名单外应用可能弹未知来源 |
| 聚好看应用商店 | ❌ IPTV/直播类全下架（政策原因） |
| 乐播投屏（DLNA）| ✅ 已采用——电视原生支持，无需安装任何东西 |
| VIDAA 局域网遥控协议 (36669/36670/7788/7799) | ❌ 国行聚好看不响应国际版 AE_AUTHORIZATION 配对 |

## 附：验证 ADB 是否存在的方法

```bash
# 快速多端口探测
for p in 5555 5037 5554 7555 8888; do nc -z -w 2 192.168.1.10 $p && echo "$p open"; done
# adb 直连尝试（即便端口非常规也试）
adb connect 192.168.1.10:5555
```

监控脚本注意：用 `nc -z -w 1` 循环探测没问题，但**杀进程要用 `pkill -9 -f "192.168.1.10 5555"`**，kill PID 可能只杀到 zsh wrapper，循环体会被拉起继续跑（本案实际发生）。
