# 01 - 电视探测与身份确认

## 起点：只知道一个 IP（192.168.1.10）

Mac 本机是 192.168.1.9（en0），与电视同网段（192.168.1.0/24，网关 .1）。

## 探测过程（方法论可复用）

### 1. 存活与 TTL
```bash
ping -c 3 192.168.1.10
# 3 packets received, ttl=64 → Linux/Unix 类系统（Windows 是 128）
```

### 2. 全端口扫描（无 nmap 时用 Python）
```python
import socket, concurrent.futures
def scan(p):
    s = socket.socket(); s.settimeout(0.6)
    try: s.connect(("192.168.1.10", p)); return p
    except: return None
    finally: s.close()
with concurrent.futures.ThreadPoolExecutor(400) as ex:
    print(sorted(r for r in ex.map(scan, range(1, 65536)) if r))
```
全量 65535 端口约 5 秒。分两次扫（1-10000、10000-65536）更快。

### 3. 端口身份鉴定

| 端口 | 身份 | 鉴定方法 |
|------|------|----------|
| 8081 | 聚好看智能家居面板 (Polymer 前端, com.jamdeo.android.jamdeosmarthome) | HTTP GET / 返回 HTML，title "Device" |
| 49152 | 乐播 DLNA MediaRenderer | SSDP M-SEARCH → description.xml |
| 7788/7799 | WebSocket 服务，回 `{"cmd":2002}` | WS 握手 101 后发 JSON 观察 |
| 36669/36670 | 海信 VIDAA 遥控协议（国际版 Home Assistant hisense_tva 用），国行不响应 AE_AUTHORIZATION | WS + AE_AUTHORIZATION 授权码试探 |
| 54321 | 聚好看 SDK 端口，无响应 | - |
| 16174 | 投屏辅助，回 `{"cmd":1008}` | 裸 TCP |
| 46019 | 回 `{"action":0,"sendType":1,"success":false}` | 裸 TCP |

### 4. SSDP 发现（最有价值）
```python
# 组播 M-SEARCH，监听 239.255.255.250:1900
msg = b"M-SEARCH * HTTP/1.1\r\nHOST: 239.255.255.250:1900\r\nMAN: \"ssdp:discover\"\r\nMX: 2\r\nST: ssdp:all\r\n\r\n"
```
返回的关键信息：
```
LOCATION: http://192.168.1.10:49152/description.xml
SERVER: Linux/3.18.16_s5, UPnP/1.0, Portable SDK for UPnP devices/1.6.13
USN: uuid:F7CA5454-...::urn:schemas-upnp-org:service:AVTransport:1
```

### 5. description.xml（身份+控制通道全在这里）
```xml
<friendlyName>客厅电视</friendlyName>
<manufacturer>LEBO</manufacturer>
<modelDescription>Lebo Media Render</modelDescription>
<modelName>HappyCast</modelName>
<URLBase>http://192.168.1.10:49152</URLBase>

```

## 经验

- macOS `arp -a` 经常查不到同网段邻居（缓存策略），别依赖它拿 MAC；SSDP/UPnP 的 description.xml 里有 MAC（uuid 尾部）
- 8081 智能家居面板的 app.js 是身份金矿：里面列举了支持的设备类型（洗衣机/冰箱/窗帘/海信门锁/科龙空调），确认是海信系
- 工厂菜单也可以看固件/MAC/机号（照片发 AI 识别即可）
