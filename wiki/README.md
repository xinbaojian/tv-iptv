## 快速上手

```bash
cd ~/workspace/python/tv-iptv
python3 tv.py                    # 启动，Ctrl+C 停止
# 手机/电脑浏览器打开 http://192.168.1.9:8899
# 点频道换台；当前频道下方「线路 1 2 3...」按钮切换源
```

## 一句话架构

```
遥控器(浏览器) ──> tv.py (8899)
                     ├─ 直连模式: 电视自己拉公网源 (首选, 零转码)
                     └─ 兜底模式: Mac ffmpeg 拉流→1080p HLS→电视从 Mac 拉
                          (直连 12 秒未确认自动切换; 4K 太重/源卡时用)
```
